# 首爾行程 App

2026/10/26–10/31 首爾六日旅遊行程，可安裝到手機主畫面的網頁 App（PWA）。

## 使用方式
1. 用 iPhone 的 Safari 打開網站
2. 點「分享」→「加入主畫面」
3. 有網路時先打開一次，之後沒網路也能使用

## 功能
- 點一下行程：看說明、地址、IG 和 NAVER 地圖連結
- 長按行程：編輯、刪除、調整順序
- 修改只存在這台手機上

## 檔案
- `index.html`：行程頁面
- `manifest.webmanifest`：App 名稱與圖示設定
- `sw.js`：離線快取
- `icon-*.png`：主畫面圖示
